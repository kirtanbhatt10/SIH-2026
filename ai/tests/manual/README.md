# Manual demo scripts

Interactive scripts that print human-readable output. They are **not** part of
the automated pytest suite — run them by hand when you want to eyeball a
module's behaviour.

```bash
python tests/manual/frequency_analyzer_demo.py
python tests/manual/spectrogram_demo.py
python tests/manual/signal_generator_demo.py
```

For the automated suites see `tests/` (pytest) and `tests/run_dsp_suite.py`.
